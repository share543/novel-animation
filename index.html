要解決的問題

用 AI 把小說做成影片，崩壞的通常不是畫質，是一致性。

你寫「林佑安穿米白色風衣、左手戴黃銅戒指」， 第一個鏡頭很完美。第二個鏡頭 AI 可能給他紅外套、多一根手指、換一張臉。 根因是每次重打 prompt，描述就會漂移。

解法：固定段與變動段分離

把 prompt 切成兩類，固定段只在設定檔寫一次，全案自動沿用。

完整 prompt ＝ ① 主體描述 ＋ ② 環境描述 ＋ ③ 鏡頭描述 ＋ ④ 畫風基底
                ↑ 從設定檔複製    ↑ 從設定檔複製     ↑ 每格不同    ↑ 從設定檔複製
                  永不手改         永不手改                     永不手改

搭配參考圖鎖定（臉部強度 0.85–0.9），角色臉就不會跳。 工具會依景別自動算出該填多少強度，你不用查表。

離線保證

使用者要求，也是硬性約束。

  • 單一檔案 — HTML + CSS + JS 全內嵌在 storyboard.html，71KB。
  • 完全離線 — 無 CDN、無框架、無 fetch，全部原生 Web API。
  • 雙擊即用 — 直接開 file:// 就能跑，不需安裝或架伺服器。
  • 相容性處理 — Safari 在 file:// 封鎖 localStorage 時自動退回記憶體並提示備份； 剪貼簿不可用時退回舊版 API。

下載後離線使用，或直接用線上版： storyboard.html

先看範例

開啟工具後點右上角「載入範例」，立刻看到完整運作 —— 2 個角色、2 個場景、8 個鏡頭（推理短篇〈雨夜來客〉單元一開場）。

建議不要照抄範例，而是載入理解結構後按「新專案」清空， 用你自己小說的第一個場景填 5 個鏡頭，生成出來確認一致性可控再往下鋪量。
