角色設定檔

參考圖流程：先用「描述字串＋畫風」文生圖 → 挑最滿意的 → 放大下載 → 存到 refs/ → 之後每個鏡頭都上傳它。
臉部參考強度 0.85–0.9 鎖臉，主體參考強度 0.4–0.6 讓姿勢構圖自由變化。

場景設定檔

偵探小說的場景通常只有 3–6 個，一開始建好之後一路沿用。 建議為每個場景做一張參考圖，主體參考強度調高（0.65–0.7）鎖住空間結構 —— 窗戶位置、書架方位靠文字描述每次都會跑掉。

鏡頭表（核心）

prompt = ①角色描述 + ②場景描述 + ③鏡頭描述 + ④畫風基底，自動組裝，點欄位即時預覽。
⚠️ 即夢限制：多人物鎖臉僅限 2 人且易生出第三個人 → 一律單人鏡頭，對話用剪輯正反打。

畫風一致？手部正常？有無多餘人物？構圖符合景別？
省積分補救順序： 局部重繪 → 消除筆 → 重繪 → 變體 → 整張重抽。 不要一不合格就重抽。

免費積分生存指南

  1. 每日簽到積分當日清零 — 每天用掉，別囤
  2. 測試用低解析度，滿意再出高清
  3. 一次生 4 張，挑選比重抽划算
  4. QC 不合格先試局部重繪
  5. 參考圖存好重用，不花積分
