# 提示詞庫（Prompt Library）

> 每個專案填一次，之後全程沿用。**這裡的字串是所有鏡頭 prompt 的基底，不手改。**

---

## 一、畫風基底字串（每個專案定一個）

決定全片統一質感。**選一種，整片不換。**

### 風格 A：寫實電影感（推薦用於推理片）

```
電影級寫實畫風，35mm 膠片顆粒感，淺景深，電影感打光，低飽和色調搭配暖色高光，專業色彩分級，高細節
```

### 風格 B：日系動畫賽璐璐

```
日系動畫賽璐璐風格，乾淨線稿，柔和賽璐璐上色，自然暖光，色彩鮮明但不飽和，背景細節豐富
```

### 風格 C：漫畫分鏡（Motion Comic 專用）

```
美式漫畫插畫風格，粗黑線稿，網點陰影，限定色盤，戲劇化打光，動態構圖
```

### 風格 D：扁平插畫

```
扁平向量插畫風格，細節簡約，幾何造型，柔和粉彩色盤，乾淨留白，現代編輯風格
```

> **建議**：偵探推理用**風格 A（寫實電影感）** —— 懸疑氛圍最自然，
> 且寫實畫面的生成品質已相當穩定。

> **中文提示詞比英文準。** 即夢對中文的理解較好，模板以中文為主。
> 英文版可作為備用欄位保留。

## 二、鏡頭語言模板（第③段用）

依景別選擇，套用在鏡頭描述前後。工具的景別下拉選單會自動帶入對應模板。

| 景別 | 模板 |
|---|---|
| 大遠景 | 極遠景，廣角，呈現廣闊環境，主體在畫面中很小 |
| 遠景 | 遠景全身鏡頭，環境與人物同時入鏡 |
| 中景 | 中景取景腰部以上，構圖自然 |
| 近景 | 中近景取景胸部以上，捕捉微妙表情 |
| 特寫 | 特寫鏡頭，突出人物面部，淺景深背景模糊 |
| 大特寫 | 微距大特寫，畫面填滿，呈現細節紋理 |
| 物件 | 物件特寫，微距細節，淺景深 |

### 參考強度對照（依景別自動建議）

| 景別 | 臉部 | 主體 | 理由 |
|---|---|---|---|
| 大遠景、遠景 | 0.30 | 0.70 | 不看臉，鎖環境結構 |
| 中景 | 0.85 | 0.50 | 平衡（最常用） |
| 近景 | 0.90 | 0.40 | 鎖臉優先 |
| 特寫、大特寫 | 0.90 | 0.35 | 臉部高度一致 |
| 物件 | — | 0.70 | 物證需跨鏡頭一致 |

## 四、負面提示詞（Negative Prompt）

**必填。** 這是 AI 影像最常見缺陷的排除清單，貼在即夢的「反向提示詞」欄位：

```
低畫質，模糊，失焦，變形，多餘手指，缺少手指，畸形手部，多餘肢體，
錯誤五官，臉部不對稱，文字，浮水印，簽名，logo，截斷，
低對比，過度飽和，塑膠皮膚，額外物體
```

英文備用版：

```
lowres, worst quality, blurry, out of focus, bad anatomy,
deformed hands, extra fingers, missing fingers, extra limbs, mutated hands,
disfigured face, asymmetric eyes, cross-eyed,
text, watermark, signature, logo, cropped,
low contrast, oversaturated, plastic skin, extra objects
```

## 五、常見問題對策

| 問題 | 對策 |
|---|---|
| 手部畸形 | 負面詞已含「畸形手部」；避免大特寫完整手掌，改用「手握著…」局部構圖 |
| 臉部每格不同 | 確認**參考圖已上傳** ＋ 臉部強度 0.85–0.9 ＋ 角色描述字串完全一致 |
| 畫風不統一 | 確認畫風基底字串每格完全一致，沒有手改 |
| 場景佈局跑掉 | 上傳**場景參考圖**，主體強度 0.65–0.70 |
| 背景雜物 | 場景描述明確指定陳設，負面詞加「額外物體」 |
| 出現文字亂碼 | 負面詞已含「文字」；需要文字改在剪輯階段用字幕卡做 |
| 生出多餘人物 | 一律單人鏡頭，不要要求兩人同框 |
| 曝光過亮／過暗 | 用局部重繪調整，不要整張重抽 |

## 六、完整 prompt 組裝範例

工具會自動組裝這四段：

```
【① 角色字串】
30 歲瘦高男子，黑色短髮自然偏分，菱形臉下顎線條銳利，
左手無名指戴一枚舊式黃銅戒指，身穿米白色風衣搭配深藍高領毛衣，神情冷靜銳利

【② 場景字串】
昏暗的偵探事務所，中央是深色木質書桌，右側整面牆為滿載舊書的書架，
左側百葉窗透進微弱夜色，桌面唯一光源是綠色罩子檯燈

【③ 鏡頭段】
中景取景腰部以上，構圖自然；偵探坐在書桌後方，手持鋼筆停在半空，視線向窗外

【④ 畫風字串】
電影級寫實畫風，35mm 膠片顆粒感，淺景深，電影感打光，低飽和色調搭配暖色高光，專業色彩分級，高細節
```

**負面提示詞**放在獨立欄位，不併入 prompt。

## 七、即夢參數設定

| 項目 | 建議 |
|---|---|
| 模型 | 最新的圖片模型（如 Seedream 系列 Pro 版） |
| 比例 | **16:9**（一開始就定，中途改等於重做） |
| 數量 | 一次 4 張挑選 |
| 參考方式 | 角色用「角色特徵」，場景用「主體」 |
| 臉部參考強度 | 0.85–0.90（遠景可降至 0.30） |
| 主體參考強度 | 0.40–0.50（場景 0.65–0.70） |
| 反向提示詞 | 直接貼上第四節的清單 |

**共通鐵律**：解析度一律 **16:9**，因為成品是橫式影片。

---

## 八、組合的邏輯（為什麼要分四段）

```
① 角色描述 ──┐
② 場景描述 ──┤ 固定段：從設定檔複製，永不手改
④ 畫風基底 ──┘
③ 鏡頭描述 ── 變動段：每格不同
```

固定段只寫一次，全案沿用。這是跨鏡頭一致性的唯一保證 ——
每次重打 prompt 就會漂移，這是 AI 生成最根本的失敗來源。
