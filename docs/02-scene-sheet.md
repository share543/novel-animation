# 場景設定檔（Scene Sheet）

> 與人物設定檔同理：**固定描述字串**，是每個鏡頭 prompt 的第二段，永遠不手改。
> 偵探小說的場景通常很少（3–6 個），一開始建好，之後一路沿用。

---

## 為什麼場景也要有參考圖

空間結構（窗戶在哪、書架方位、門的位置）**靠文字描述每次都會跑掉**。

你寫「右側整面牆為滿載舊書的書架」，AI 第一次放右邊，第三次可能放左邊。
觀眾在同一集裡看到房間佈局改變，會直接出戲。

**場景參考圖 ＋ 主體強度 0.65–0.70** 可以鎖住空間結構，
同時讓人物姿勢、光線變化仍然自由。

---

## 使用規則

1. 每個場景建立一張卡
2. 寫出**一段固定描述字串**（40–60 字）
3. 生成參考圖，存到 `refs/`
4. 記錄**主體參考強度**（建議 0.65–0.70）
5. **不要**在鏡頭表裡改寫場景的措辭

---

## 場景卡模板

### 場景名：＿＿＿

| 欄位 | 內容 |
|---|---|
| 場景類型 | 室內／室外 |
| 出現單元 | 第 \_\_ 單元 |
| 空間結構 | 格局與固定的空間關係（門窗方位、主要家具位置） |
| 固定陳設 | 一定會出現的 2–4 樣物件 |
| 光線 | 光源位置與性質（單一檯燈／百葉窗透光／霓虹反射） |
| 色調 | 冷色／暖色／高對比／低飽和 |
| 氛圍基調 | 情緒色調（壓抑／冷清／緊張） |
| 參考圖 | `refs/xxx.png` |
| 主體參考強度 | `0.65` |

**固定描述字串**（複製這段到每個鏡頭的 prompt，接在角色描述之後）
```
[40–60 字：空間類型 + 幾項固定陳設 + 光線 + 氛圍]
```

> **寫法要點**：寫「可見的物件」而不是「氣氛形容詞」。
> 「左側百葉窗透進微弱夜色」可以，「氣氛很壓抑」不行。

## 範例（推理小說常用場景）

### 場景名：偵探事務所

| 欄位 | 內容 |
|---|---|
| 場景類型 | 室內 |
| 出現單元 | 第 1、2、3 單元（多數場景） |
| 空間結構 | 中央書桌，右牆整面書架，左側百葉窗 |
| 固定陳設 | 深色木質書桌、綠色罩子檯燈、滿載舊書的書架 |
| 光線 | 夜晚，桌面唯一光源是綠色罩子檯燈，左側百葉窗透進微弱夜色 |
| 色調 | 暖黃為主、暗部偏青，冷暖對比 |
| 氛圍基調 | 壓抑、孤獨 |
| 參考圖 | `refs/office.png` |
| 主體參考強度 | `0.65` |

**固定描述字串**
```
昏暗的偵探事務所，中央是深色木質書桌，右側整面牆為滿載舊書的書架，
左側百葉窗透進微弱夜色，桌面唯一光源是綠色罩子檯燈，暖黃光暈與青藍暗部形成冷暖對比
```

### 場景名：命案現場（公寓）

| 欄位 | 內容 |
|---|---|
| 場景類型 | 室內 |
| 出現單元 | 第 1 單元 |
| 空間結構 | 客廳為主，窗戶在畫面右側 |
| 固定陳設 | 翻倒的椅子、散落文件、角落血跡、半拉的窗簾 |
| 光線 | 白天陰天，窗戶為主光源，室內偏暗 |
| 色調 | 低飽和冷灰 |
| 氛圍基調 | 不安、冷硬 |
| 參考圖 | `refs/crime-scene.png` |
| 主體參考強度 | `0.70` |

**固定描述字串**
```
日式公寓的客廳，地板散落著撕破的文件，一把椅子翻倒在旁，
角落有深色血跡斑塊，窗簾半拉使室內光線昏暗，低飽和冷灰色調
```

### 場景名：雨夜街道

| 欄位 | 內容 |

| 出現單元 | 第 1、4 單元 |

深夜的舊城區街道，兩側是密集的老式公寓騎樓，濕滑柏油路面反射霓虹招牌，
細雨中遠處路口亮著一盞昏黃路燈

## 場景切換的處理

- **同一場景的連續鏡頭** → 用同一張場景參考圖，只改景別與運鏡 → 一致性高
- **切換場景** → 換成新場景的描述字串與參考圖
- **同場景不同時間**（白天／夜晚）→ **當成兩個不同場景建卡**，
  光線差異太大，共用一張參考圖會打架
- 剪輯時用**淡入淡出**或**黑場**做銜接，不要硬切

---

## 一致性檢查清單

- [ ] 空間格局一致（門窗、家具方位）
- [ ] 光線方向一致
- [ ] 固定陳設沒少沒多
- [ ] 色調與氛圍基調一致
- [ ] 沒有出現現代物件穿幫（時代錯誤）

---

## 建立順序

1. 讀完小說，列出所有出現的場景
2. 合併同性質場景（「事務所」不必分「上午的事務所」「下午的事務所」）
3. 每個場景寫 1 段描述字串 → 生成 1 張參考圖 → 記錄主體強度
4. 全部存到 `refs/`
