## 檔案命名規則

```
{單元}_{shot_id}_v{版本}.png

例：U1_S003_v2.png
```

版本遞增，**永不覆蓋舊檔**。棄用的也要留著 —— 有時候客戶或你自己會回頭說
「還是第一版好」。

## QC 檢查（生成後逐張）

- [ ] 角色臉與參考圖一致？
- [ ] 服裝一致？
- [ ] 標誌性特徵有出現（戒指、眼鏡、傷疤）？
- [ ] 畫風與其他鏡頭一致？
- [ ] 手部正常？
- [ ] 有無莫名其妙的文字或亂碼？
- [ ] 構圖是否符合景別要求？
- [ ] **有沒有生出多餘人物？**

## 補救順序（省額度）

不合格**不要直接重抽** —— 先試便宜的補救：

| 順序 | 工具 | 適用 | 成本 |
|---|---|---|---|
| 1 | **局部重繪** | 單一部位錯（手指、眼神、物件） | 低 |
| 2 | **消除筆** | 多餘物件、雜點、浮水印 | 低 |
| 3 | **重繪** | 保留構圖重新生成 | 中 |
| 4 | **變體** | 基於選中圖再出 4 張 | 中 |
| 5 | **整張重抽** | 以上都失敗 | 高 |

**畫面大致對 → 用局部重繪。畫面根本錯了 → 才重抽。**

多數情況局部重繪就能解決，而且能保住已經滿意的構圖與光線。

## 起草時的先後順序

1. **先建參考圖**（角色、場景、物證）—— 這是所有鏡頭的前提
2. 再批次生成鏡頭
3. 每生完一批立刻更新索引與狀態
4. 全部 ✅ 之後才進剪輯
