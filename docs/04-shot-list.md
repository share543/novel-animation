# 鏡頭表（Shot List）— 核心文件

> **這份決定成片。** 每個鏡頭一列，旁白、景別、運鏡、時長、完整 prompt 都在這裡。
> 剪輯時照這份表做，生成時照這份表的 prompt 出圖。

---

## 每列的組成

```
shot_id → 旁白 → 景別 → 運鏡 → 時長 → 第③段鏡頭描述 → 參考設定 → 檔案
```

**四段式 prompt**

```
① 角色描述 ＋ ② 場景描述 ＋ ③ 鏡頭描述 ＋ ④ 畫風基底
   ↑從 01 複製   ↑從 02 複製    ↑ 每格不同    ↑從 05 複製
     永不手改       永不手改                    永不手改
```

工具的鏡頭表會**自動組裝**這四段，並依景別自動算出參考強度 ——
你只需要填第③段。

## 景別（Shot Size）

| 名稱 | 用於 | 情緒效果 | 臉部／主體強度 |
|---|---|---|---|
| 大遠景 | 交代環境、案件現場 | 孤獨、渺小 | 0.30／0.70 |
| 遠景 | 人物全身＋場景關係 | 客觀、距離感 | 0.30／0.70 |
| 中景 | 人物腰部以上，**最常用** | 對話、敘事 | 0.85／0.50 |
| 近景 | 胸部以上 | 情緒、表情 | 0.90／0.40 |
| 特寫 | 頭部／手部 | 強調、線索、衝擊 | 0.90／0.35 |
| 大特寫 | 眼睛、戒指、筆跡、血跡 | **推理片最有力** | 0.90／0.35 |
| 物件 | 兇器、信件等物證 | 線索提示 | —／0.70 |

**偵探片節奏**：中景敘事 → 特寫點出線索 → 大特寫給關鍵物證。

**為什麼遠景把臉部強度降到 0.30**：遠景看不到臉，鎖臉沒有意義，
反而會把參考圖的姿勢一起鎖住，讓構圖僵化。降低臉部強度換取環境自由度。

## 運鏡（Ken Burns）

| 類型 | 效果 | 適用 |
|---|---|---|
| 固定 | 靜止 | 對話、字幕呈現 |
| 緩慢推近 | 聚焦、緊張感升溫 | 發現線索、情緒高點 |
| 緩慢拉遠 | 揭示環境、收束 | 段落結尾、場景交代 |
| 緩慢左移／右移 | 掃視、串連空間 | 交代場景細節 |
| 輕微晃動 | 不安、崩解 | 案情逆轉瞬間 |

**全部用「緩慢」**。剪輯軟體裡設 2–4 秒完成，速度要慢到觀眾不會覺得在動，
但停住時又能聚焦。

## shot_id 命名規則

```
S + 三位數字：S001, S002, S003
```

單元編號可加前綴：`U1-S001`、`U2-S001`。

**永遠不要改編號** —— 素材索引靠它對應。要插入新鏡頭就用 `S002b`，
不要重新編號造成下游檔案錯亂（工具裡的「重新編號」慎用）。

---

## 每單元的鏡頭數估算

10 分鐘單元 ≈ **35–50 個鏡頭**（平均每個 12–17 秒）

不用每句旁白配一個畫面 —— 有些旁白可以配同一個畫面用不同運鏡，
有些停頓就是同一畫面定格。**節奏比數量重要。**

---

## 填表順序

分三階段填，比較不會卡住：

1. 先只填 **shot_id ＋ 旁白 ＋ 時長** → 確認切分合理
2. 再填 **景別 ＋ 運鏡 ＋ 角色/場景** → 確認節奏（參考強度自動算出）
3. 最後填 **③ 鏡頭描述 ＋ 檔案** → 準備生成

---

## 時長怎麼估

工具的「依旁白字數估算時長」用：

```
秒數 = 旁白字數 ÷ 字速（預設 260 字/分）× 60
```

推理片用 260 字/分（要留白讓觀眾推想）。新聞口播才用 300+。
估算後可手動微調 —— 停頓多的地方要加秒數。
