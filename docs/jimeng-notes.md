# 即夢實務要點

以即夢（jimeng.jianying.com）為目標生成工具的實務筆記。

---

## 一致性機制：用「參考圖」，不是 seed

即夢的一致性靠**參考圖 ＋ 參考強度**，比 seed 鎖定可靠得多。

```
① 首次：文生圖生成角色 → 挑滿意的 → 放大下載 → 存 refs/
② 之後：每個鏡頭上傳這張參考圖
        參考方式：角色特徵
        臉部參考強度 0.85–0.9   ← 鎖臉
        主體參考強度 0.4–0.6    ← 讓姿勢構圖自由變化
```

場景參考圖則用「主體」方式，主體強度調高（0.65–0.7）鎖住空間結構。

### 為什麼要分開調兩個強度

| 參數 | 調高 | 調低 |
|---|---|---|
| 臉部參考強度 | 臉完全一致，但表情僵化 | 表情自然，但臉會漂 |
| 主體參考強度 | 構圖受限、容易複製參考圖的姿勢 | 姿勢自由，但可能走樣 |

**遠景對臉要求低**（放 0.30，換取環境自由度），
**特寫對臉要求高**（拉 0.90，犧牲姿勢自由）。這就是景別對照表的由來。

## 三個必須先知道的限制

### 1. 多人物鎖臉僅限 2 人，且容易生出第三個人

最常翻車的地方。要求兩人同框時，AI 經常：
- 把第二個人的臉套到第一個人身上
- 無中生有出現第三個人
- 兩人的衣服混在一起

**解法：一律用單人鏡頭。** 對話場景靠剪輯正反打（A 說 → B 說 → A 反應），
這在電影語言上本來就是標準做法，不是妥協。

### 2. 免費版有浮水印、最高 720P

水印不影響觀感但影響專業度。要上架乾淨影片需付費去水印。

### 3. 畫中文字會出錯

即夢的文字渲染仍不可靠，會出現錯字或亂碼。

**解決：不要在 prompt 要求文字。** 所有文字（招牌、信件、報紙標題）
改在剪輯階段用字幕卡或修圖軟體疊上去。

## 免費額度生存策略

1. **每日簽到額度當日清零** — 每天用掉，別囤積
2. **測試用低解析度**，滿意再出高清（實際扣點以介面顯示為準）
3. **一次生 4 張挑選**，比重抽划算
4. **QC 不合格先試局部重繪**，不要整張重抽
5. **參考圖存好重用**，生成參考圖不額外消耗

## 補救工具與使用順序

| 順序 | 工具 | 適用 | 成本 |
|---|---|---|---|
| 1 | **局部重繪** | 單一部位錯（手指、眼神、物件） | 低 |
| 2 | **消除筆** | 多餘物件、雜點、浮水印 | 低 |
| 3 | **重繪** | 保留構圖重新生成 | 中 |
| 4 | **變體** | 基於選中圖再出 4 張 | 中 |
| 5 | **整張重抽** | 以上都失敗 | 高 |

**畫面大致對 → 用局部重繪。畫面根本錯了 → 才重抽。**

## 提示詞要點

- **中文比英文準** — 即夢對中文理解較好，模板以中文為主
- **中文標點要用全形**（，。）而非半形
- **比例一開始就定** — 16:9 定好後中途改等於全部重做
- **描述具體可視** — 「神情冷靜銳利」優於「看起來很專業」
- **固定描述字串** — 角色的描述一次寫好，之後完全複製不手改
- **反向提示詞要填** — 過濾低畫質、多餘手指、錯誤五官、文字浮水印
