# 人物設定檔（Character Sheet）

> **這份檔案決定成敗。** AI 生成影片最常崩壞的地方就是「每格看起來是不同的人」。
> 這裡的「固定描述字串」是每個鏡頭 prompt 的第一段，**建立後永遠不手改**。

---

## 使用規則

1. 每個角色建立一張卡
2. 寫出**一段固定描述字串**（50–80 字），之後每個鏡頭都原樣複製
3. **生成參考圖**，挑滿意的放大下載 —— 這是跨鏡頭一致性的唯一保證
4. 記錄**臉部**與**主體**參考強度，之後每個鏡頭照填
5. **不要**在鏡頭表裡改寫角色的描述措辭

---

## 為什麼是參考圖，不是 seed

即夢的一致性靠**參考圖 ＋ 參考強度**，比記 seed 數字可靠得多：

```
① 首次：用描述字串文生圖 → 挑滿意的 → 放大下載 → 存 refs/
② 之後：每個鏡頭上傳這張參考圖
        參考方式：角色特徵
        臉部參考強度 0.85–0.9   ← 鎖臉
        主體參考強度 0.4–0.6    ← 讓姿勢構圖自由變化
```

| 參數 | 調高 | 調低 |
|---|---|---|
| 臉部參考強度 | 臉完全一致，但表情僵化 | 表情自然，但臉會漂 |
| 主體參考強度 | 構圖受限、容易複製參考圖姿勢 | 姿勢自由，但可能走樣 |

**遠景對臉要求低**（放 0.30，換取環境自由度）；**特寫對臉要求高**（拉 0.90）。
工具的鏡頭表會依景別自動算出建議值。

## 角色卡模板

### 角色名：＿＿＿

| 欄位 | 內容 |
|---|---|
| 角色定位 | 主角／嫌疑人／配角／旁白者 |
| 外貌特徵 | 年齡、身高、髮型、臉型、膚色 |
| 標誌性特徵 | 辨識用記憶點（例：總戴圓框眼鏡、左眉有疤、黃銅戒指） |
| 服裝 | **固定不變的單一裝扮**（不要換裝，會大幅增加不一致） |
| 表情基調 | 日常表情樣本（供參考圖使用） |
| 參考圖 | `refs/xxx.png`（生成後存檔） |
| 臉部參考強度 | `0.85`（遠景可降到 0.30） |
| 主體參考強度 | `0.50`（特寫可降到 0.35） |

**固定描述字串**（複製這段到每個鏡頭的 prompt 開頭）
```
[50–80 字，必須包含：性別年齡 + 髮型 + 臉部特徵 + 固定服裝 + 一個辨識記憶點]
```

> **寫法要點**：描述要「具體可視」。「神情冷靜銳利」可以，「看起來很專業」不行 ——
> AI 無法把抽象形容詞轉成畫面。

## 範例（推理小說主角）

### 角色名：偵探 林佑安

| 欄位 | 內容 |
|---|---|
| 角色定位 | 主角 |
| 外貌特徵 | 30 歲男性，瘦高，黑色短髮偏分，菱形臉，下顎線條明顯 |
| 標誌性特徵 | 左手無名指戴舊式黃銅戒指 |
| 服裝 | 米白色風衣 + 內搭深藍高領毛衣（**全片不換**） |
| 表情基調 | 冷靜、眼神銳利、嘴角略收 |
| 參考圖 | `refs/lin-youan.png` |
| 臉部參考強度 | `0.85` |
| 主體參考強度 | `0.50` |

**固定描述字串**
```
30 歲瘦高男子，黑色短髮自然偏分，菱形臉下顎線條銳利，
左手無名指戴一枚舊式黃銅戒指，身穿米白色風衣搭配深藍高領毛衣，神情冷靜銳利
```

**首張參考圖的生成 prompt** ＝ 上面的描述字串 ＋ 畫風基底 ＋ `中景取景腰部以上`

## 一致性檢查清單

每批生成後逐項確認：

- [ ] 髮型／瀏海形狀一致
- [ ] 臉型與五官比例一致
- [ ] 標誌性特徵有出現（戒指、眼鏡、傷疤）
- [ ] 服裝顏色與款式一致
- [ ] 沒有出現角色不該有的配件
- [ ] 沒有多餘人物入鏡

---

## ⚠️ 多角色同框（即夢限制）

**即夢的多人物鎖臉僅限 2 人，而且容易無中生有生出第三個人。**

常見失敗：
- 把第二個人的臉套到第一個人身上
- 兩人的衣服混在一起
- 憑空多出第三個人

**解法：一律用單人鏡頭。** 對話場景靠剪輯正反打：

```
A 說 → 切 B 的反應 → 切 A 的反應 → 切回 B
```

這在電影語言上本來就是標準做法，不是妥協 —— 而且比硬生同框好看。
工具的鏡頭表有「角色」欄位，一個鏡頭只選一個角色。
